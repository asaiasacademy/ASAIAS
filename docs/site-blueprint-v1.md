# Static Site Blueprint v1

Статус: site blueprint v1.

## Principle

Первый сайт остается простым:

```text
GitHub repo -> static website -> GitHub Pages / static hosting
```

Не начинать с тяжелого портала, LMS или private dashboard.

## Required Sections

- Home;
- About / Background;
- Start Here;
- Courses;
- Labs;
- Certificates;
- Research;
- Languages;
- Pricing;
- Apply / Join;
- Contact.

## Safety Copy

The site must visibly avoid:

- accreditation claims;
- guaranteed result claims;
- automatic certificate claims;
- unconfirmed partnerships;
- production claims for demo;
- private student data exposure.
