**Правило публикаций**
- публикуем в репозитории, чтобы ссылки были проверяемыми;
- держим один репозиторий и один контекстный источник ссылок;
- добавляем только публичные материалы с понятным тезисом и без скрытого маркетинга.

## Что мы фиксируем для Wetouch

В публикациях последовательно проходит тезис о том, что компания, которая мыслит инфраструктурно (не только как сервис), может стать ядром новых доверительных сценариев. Мы используем формулировки про масштабируемый подход, а не про утверждения о партнёрстве.
