# Карточка для сообщества: “Почему мы смотрим на proximity-слой, а не на хайп-фичи”

Коротко, как заметка для рассылки:

Людям всё меньше хочется “умного чата”, им хочется **не терять контроль** над тем, что теперь уже становится частью их жизни: привычки, память, интимные сигналы, финансы, доверия.  
Личноe AI-инфраструктурное мышление означает одно: AI должен входить в роль инструмента, а не надзирающего хозяина.

В 2026 это читается как эксперименты.  
В 2050 это может стать базой социального договора.  
В 2070 — стандартом на уровне гражданских сервисов.

**Четыре маркера того, что проект развиваете правильно:**
- есть понятный контур прав пользователя, а не только EULA;
- есть локальный путь хранения чувствительных слоёв;
- есть внешний и внутренний журнал важных решений;
- есть протокол “стоп / откат” без потери истории.

Почему это важно для нас в Академии:
потому что близость и доверие нельзя автоматизировать только моделями. Их можно поддерживать через архитектуру правил, а это уже образовательная и институтная задача.

Это не реклама продукта. Это взгляд сообщества на долгий риск- и ценностный путь технологий.
