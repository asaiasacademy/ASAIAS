## Blocked Until Safety Review

Adult-device control frameworks, explicit sexual device protocols and coercive companion projects are not part of the baseline watchlist.

They require a separate review covering:

- adult-only verification;
- consent model;
- device safety;
- emergency stop;
- data privacy;
- legal exposure;
- platform policy;
- abuse and coercion risks.

## Research Questions

1. How should long-term memory be consented, edited, exported and deleted?
2. What is a safe character layer that avoids dependency and manipulation?
3. Which voice stack can run locally with acceptable latency?
4. How should device actuation be sandboxed and rate-limited?
5. What is the minimum safe embodied response API?
6. Which claims are safe for public communication?
