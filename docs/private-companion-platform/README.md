# Приватная AI-платформа близости

Статус: strategic direction baseline v1.

## Название направления

**Приватная AI-платформа близости, где персональный компаньон получает память, голос, характер и телесный отклик через устройства.**

Рабочее английское имя: **Private Embodied Companion AI Platform**.

## Что это

Это направление изучает private, consent-first, adult-only AI systems, где персональный компаньон может иметь:

- долгую память;
- голосовой интерфейс;
- устойчивый характер / persona layer;
- эмоциональную динамику;
- avatar / digital human слой;
- безопасный телесный отклик через устройства, haptics, IoT and wearables;
- локальное хранение чувствительных данных;
- строгие границы согласия и отключения.

## Почему это важно для Академии

Это перспективная область на пересечении:

- AI companionship;
- agentic memory;
- voice AI;
- affective computing;
- local-first AI;
- human-computer intimacy;
- embodied interfaces;
- IoT and haptics;
- privacy engineering;
- consent and safety governance.

## Главный принцип

Направление не строится как "романтический чатбот". Оно изучается как **частная инфраструктура присутствия, памяти, голоса, характера и безопасного отклика**.

## Product Stack

```text
user consent profile
  -> private memory vault
  -> personality / character engine
  -> voice input/output
  -> emotional state model
  -> device and haptics control layer
  -> safety governor
  -> audit and delete controls
```

## Обязательные границы

- adult-only;
- explicit consent for every memory and device capability;
- no hidden recording;
- no biometric or intimate inference without opt-in;
- no manipulation, coercion or dependency design;
- no imitation of real people without permission;
- no unsafe device actuation;
- emergency stop for device layer;
- local-first storage where possible;
- export and delete controls;
- source map before public claims.
