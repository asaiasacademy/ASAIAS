# Certificate 01: AI Management and Autonomous Systems Foundations

Статус: certificate review path draft v1.

## Назначение

Сертификат подтверждает, что участник прошел review учебной работы по Course 01 и представил минимальный evidence pack.

## Главное правило

```text
Деньги платятся за проверку, а не за автоматическое одобрение.
```

## Что проверяется

- понимание AI-native operating models;
- качество system map;
- безопасность demo;
- наличие human-in-the-loop;
- корректность risk notes;
- ясность evidence pack;
- способность объяснить ограничения работы.

## Что сертификат не гарантирует

- трудоустройство;
- доход;
- экспертный статус вне области проверенной работы;
- production-ready implementation;
- юридическую, финансовую, медицинскую или налоговую пригодность решений;
- признание третьими сторонами без отдельного соглашения.

## Decision States

| State | Meaning |
|---|---|
| Approved | evidence достаточен для certificate |
| Revision Requested | нужна доработка и повторный review |
| Not Approved | evidence не соответствует минимальному уровню |

## Public Wording

Разрешенная формулировка:

```text
Certificate path is based on review of submitted work and evidence. Payment covers review, not automatic approval.
```

## Private Data

Certificate record может содержать student ID, course ID, review date, reviewer ID, decision state и public certificate ID. Email, payment data и private notes хранятся в CRM/private table, не в GitHub.
