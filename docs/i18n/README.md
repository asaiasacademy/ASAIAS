## Rule

Каждая языковая версия должна сохранять:

- project status;
- no-accreditation claim;
- no guarantee claim;
- review-not-approval certificate rule;
- source map requirement;
- privacy rule for student data.

## Publication Rule

Все статьи, эссе, публикации, заметки и исследования публичного слоя ASAIAS должны выходить минимум на шести рабочих языках:

- ru;
- en;
- es;
- ar;
- zh;
- fr.

Любое превью, карточка, изображение с текстом, подпись или другой визуальный слой вокруг материала должен быть на том же языке, что и сам материал.
