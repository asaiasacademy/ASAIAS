# Ecosystem Intelligence Pass 002

Статус: internal watch pass v1.

## Focus

Второй проход по экосистеме смещает фокус с общей protocol literacy к следующему вопросу:

как выглядит governable runtime для agentic systems.

Теперь нас интересуют не только протоколы и governance frameworks, но и:

- traces;
- eval loops;
- runtime visibility;
- human intervention surfaces;
- reviewable system state.
