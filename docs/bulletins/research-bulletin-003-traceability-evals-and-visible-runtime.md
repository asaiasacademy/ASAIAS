# Research Bulletin 003

Статус: internal draft v1.

## Working Thesis

Следующая институциональная зрелость AI systems определяется не только способностью выполнять задачи.

Она определяется тем, насколько система:

- observable;
- traceable;
- evaluable;
- reviewable;
- human-approvable.

Именно поэтому visible runtime становится не технической деталью, а частью trust architecture.

## What We See

### 1. Agent systems are being described as workflows, not only prompts

Официальная линия вокруг agent systems показывает, что зрелая система строится как управляемый workflow с инструментами, контекстом, состоянием, проверками и результатом.

Source basis:

- `SRC-018`
- `SRC-024`

### 2. Traceability is becoming normal engineering, not a luxury add-on

Phoenix и Langfuse особенно хорошо показывают культурный сдвиг:

- traces become expected;
- prompts become versioned artifacts;
- run inspection becomes part of quality work;
- observability becomes trust language.

Source basis:

- `SRC-030`
- `SRC-031`

### 3. Evaluation is moving closer to deployment discipline

Если evals описываются как регулярная часть agent lifecycle, то организация уже не может серьёзно говорить о scale without measurement.

Source basis:

- `SRC-024`
- `SRC-032`

### 4. Visible runtime makes human approval real

Human approval без видимости хода работы часто остаётся слабым символом.

Visible runtime усиливает approval, потому что человек может видеть:

- what happened;
- where the system pulled context from;
- what tools were involved;
- where uncertainty appeared;
- what should be corrected or archived.

## What This Means For ASAIAS
