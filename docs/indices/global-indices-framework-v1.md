# Global Indices Framework v1

Статус: official ASAIAS indices baseline v1.

## Naming Rule

Все индексы публикуются как часть семейства:

**ASAIAS Global AI Indices**

Это официальный индексный контур ASAIAS. Он не означает государственную сертификацию, лицензирование или внешний регуляторный статус.

## Index Family

### 1. ASAIAS Global Frontier Labs Index

Сокращение: `AGFLI`

Что измеряет:

- силу frontier research;
- качество model releases;
- темп публичных technical updates;
- глубину экосистемного влияния;
- наличие верифицируемых источников.

### 2. ASAIAS Global Autonomous Systems Index

Сокращение: `AGASI`

Что измеряет:

- зрелость agentic workflows;
- автономные контуры;
- orchestration depth;
- integration with tools, memory and execution;
- operational reliability claims supported by evidence.

### 3. ASAIAS Global AI Governance and Responsibility Index

Сокращение: `AGGRI`

Что измеряет:

- governance maturity;
- review discipline;
- responsibility mapping;
- trust, safety and verification posture;
- public clarity of limits and accountability.

### 4. ASAIAS Global AI Education and Literacy Index

Сокращение: `AGELI`

Что измеряет:

- educational clarity;
- quality of public learning materials;
- usefulness for students, researchers and institutional teams;
- multilingual accessibility;
- academic discipline of explanations.

### 5. ASAIAS Global AI Ecosystem Signal Index

Сокращение: `AGESI`

Что измеряет:

- event relevance;
- speaker quality;
- conference density;
- ecosystem visibility;
- partnership and influence signals.

### 6. ASAIAS Global AI Safety and Verification Index

Сокращение: `AGSVI`

Что измеряет:

- eval maturity;
- safety posture;
- verification practices;
- red-team visibility;
- operational caution in public claims.

## Entity Types

Индексы могут ранжировать:

- companies;
- labs;
- research groups;
- platforms;
- autonomous systems;
- conferences;
- speakers;
- ecosystem organizations.

## Output Types

Публичный weekly output должен включать:

- top 10 global ranking;
- movers up / movers down;
- new entrants;
- methodology note;
- confidence note;
- source-backed short commentary.

## Scoring Principle

Каждый индекс считает итоговый балл по шкале `0-100`.

Финальный weekly ranking = normalized score + confidence adjustment + editorial integrity check.

## Confidence Layer

Кроме rank score, каждая запись получает:

- `High confidence`
- `Medium confidence`
- `Low confidence`

Confidence зависит от количества и качества источников, свежести данных и устойчивости сигнала.

## Publication Standard

Каждый weekly release должен содержать:

- freeze date;
- universe definition;
- scoring rubric;
- what changed this week;
- correction policy;
- no-endorsement note where relevant.
