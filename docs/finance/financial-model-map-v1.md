# Financial Model Map v1

Статус: map v1.

```text
public proof
  -> free self-study
  -> application
  -> CRM card
  -> offer
  -> payment / scholarship / grant support
  -> cohort or self-study
  -> demo
  -> evidence
  -> paid review
  -> certificate decision
  -> alumni / contributor / partner route
```

## Revenue Streams

| Stream | Buyer | Delivery | Risk Control |
|---|---|---|---|
| Course cohort | student / team | sessions and assignments | no guaranteed outcomes |
| Review | student / organization | submitted work review | payment not approval |
| Research briefing | organization | briefing and Q&A | no legal/investment advice |
| Institutional package | organization | pilot cohort and report | scoped proposal |
| Sponsorship | sponsor | public support | no influence on review |
| Grant | grantmaker | funded public-interest work | reporting and disclosure |

## Free Layer

The free layer creates trust and access:

- site;
- Start Here;
- public roadmap;
- first demo description;
- selected bulletins;
- contribution rules.

## Paid Layer

The paid layer funds time-intensive work:

- cohort facilitation;
- review;
- feedback;
- reporting;
- institutional integration.
