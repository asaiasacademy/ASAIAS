# Money Flow v1

Статус: draft v1.

## Student Flow

```text
student
  -> application
  -> offer
  -> payment or scholarship decision
  -> course access
  -> demo/evidence
  -> review payment if applicable
  -> review
  -> certificate decision
```

## Organization Flow

```text
organization lead
  -> discovery call
  -> proposal
  -> pilot scope
  -> payment / sponsorship / grant
  -> pilot cohort
  -> report
  -> next route
```

## Money Allocation

Suggested pilot allocation:

| Allocation | Target |
|---|---:|
| teaching and review | 40% |
| platform and operations | 20% |
| research and content | 15% |
| scholarship fund | 15% |
| reserve | 10% |

Targets are planning assumptions, not binding accounting until legal and treasury setup is complete.

## Controls

- no private payment data in GitHub;
- every paid offer has scope;
- every review has decision state;
- every scholarship has separate record;
- every sponsorship/grant has source and purpose.
