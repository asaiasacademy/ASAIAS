# Public Roadmap

Статус: public pilot roadmap v1.

## Phase 01: Academy Baseline

Цель: собрать один управляемый образовательный маршрут.

- identity document;
- Start Here;
- flagship course;
- demo;
- certificate review path;
- research bulletin;
- finance model;
- student intake;
- CRM schema;
- site blueprint;
- test student route;
- test organization route.

## Phase 02: Site + Intake v1

Цель: сделать простой static website и заявку.

- Home;
- About / Background;
- Start Here;
- Courses;
- Labs;
- Certificates;
- Research;
- Languages;
- Pricing;
- Apply / Join;
- Contact.

## Phase 03: Test Cohort

Цель: провести один тестовый student path.

```text
site -> application -> CRM card -> course -> demo -> evidence -> review -> certificate
```

## Phase 04: Organization Pilot

Цель: провести один test organization path.

```text
site -> partner lead -> CRM organization card -> discovery call -> proposal -> pilot cohort -> report
```

## Expansion Gate

Новые курсы, сложная LMS, paid portal и юридическое оформление рассматриваются только после test cohort, organization pilot и проверки financial model v1.
