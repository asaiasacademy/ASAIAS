# Course 01: AI Management and Autonomous Systems Foundations

Статус: flagship course draft v1.

## Название

AI Management and Autonomous Systems Foundations.

## Аудитория

- руководители, founders и operators;
- product managers and AI managers;
- engineers, переходящие к agentic systems;
- преподаватели и образовательные архитекторы;
- analysts, researchers и governance teams.

## Результат обучения

Участник проектирует базовую AI-native operating system для команды, организации, исследовательского центра или академии и показывает evidence через учебное demo, risk notes и короткую defense-записку.

## Модули

| Module | Topic | Output |
|---|---|---|
| 01 | AI-native operating models | карта текущей системы |
| 02 | LLMs, agents and orchestration | схема agent workflow |
| 03 | Prompt engineering for management | набор рабочих prompts |
| 04 | RAG and knowledge systems | knowledge base outline |
| 05 | Autonomous workflows | safe workflow map |
| 06 | AI governance and evaluation | risk and review checklist |
| 07 | Academy / organization as knowledge operating system | capstone system map |

## Задания

1. Описать проблему и аудиторию.
2. Построить карту знаний и процессов.
3. Выбрать один безопасный agentic workflow.
4. Создать учебное demo без production-claims.
5. Описать risks, human-in-the-loop и review criteria.
6. Подготовить evidence pack.
7. Защитить capstone на review.

## Evidence

Минимальный evidence pack:

- course notes;
- system map;
- workflow diagram;
- demo README;
- risk checklist;
- short reflection;
- reviewer comments.

Evidence не должен содержать private data клиентов, студентов или организаций.

## Certificate Path

```text
application -> course participation -> demo -> evidence pack -> review -> certificate decision
```

Сертификат выдается только после review. Оплата review не означает автоматическое одобрение.
