# Launch Logistics Model

Статус: launch model v1.

## Main Route

```text
Public proof
  -> website
  -> Start Here
  -> course/demo/certificate
  -> application
  -> CRM card
  -> cohort
  -> review
  -> certificate
  -> alumni/contributor/partner route
```

## Public Proof

GitHub is the official proof layer for documents, roadmap, decisions and source map. It does not store private student data.

## Website

The website is the main entry point and routes users to Start Here, course, labs, certificate, pricing and application.

## Application

Student intake collects minimal required information and sends it to a private CRM/private table.

## CRM Card

Every applicant receives a student ID and operational next action.

## Cohort

The first cohort tests Course 01 only.

## Review

Review checks evidence, not payment status. Payment covers reviewer work, not approval.

## Certificate

Certificate is issued only after an approved review state.

## Alumni / Contributor / Partner Route

After completion, the person or organization may move to:

- alumni community;
- contributor route;
- lab route;
- organization pilot route;
- partner discussion route.

## Test 01: One Student

```text
site -> application -> CRM card -> course -> demo -> evidence -> review -> certificate
```

Success criteria:

- student understands Start Here in 30 seconds;
- CRM card can be created without GitHub private data;
- course assignment is clear;
- demo is safe;
- review decision can be made;
- certificate rule is understood.

## Test 02: One Organization

```text
site -> partner lead -> CRM organization card -> discovery call -> proposal -> pilot cohort -> report
```

Success criteria:

- organization understands offer;
- discovery has clear scope;
- proposal avoids unsupported claims;
- pilot cohort has owner and timeline;
- report separates facts, findings and recommendations.
