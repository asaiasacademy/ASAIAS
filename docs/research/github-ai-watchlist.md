# GitHub AI Watchlist

Статус: active watchlist v1.

## Purpose

ASAIAS watches key GitHub repositories and developer ecosystems connected with AI, LLMs, agents, AGI/ASI research tooling, evaluation, safety and open model infrastructure.

This is not "all AI on GitHub" literally. GitHub has too much noisy, duplicated and unsafe material. The operating rule is curated coverage first, then expansion through issues and PRs.

## Expansion Rules

Add new repositories when they are relevant to at least one ASAIAS track:

- AI management;
- agentic systems;
- AGI/ASI research tooling;
- AI governance;
- evaluations and benchmarks;
- safety, trust and verification;
- open model infrastructure;
- AI-native education.

Avoid noisy watch additions:

- deepfake-first tools without safety value;
- investment/trading agents without research value;
- prompt dumps without review process;
- abandoned repositories;
- unsupported "AGI" marketing projects.
