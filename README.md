# ASAIAS

**Академия стратегического управления искусственным интеллектом и автономных систем**

Статус: public pilot baseline v1. Репозиторий фиксирует академическую, образовательную, исследовательскую и финансовую основу запуска до регистрации юридического лица и до масштабирования.

## Что это

ASAIAS проектируется как образовательная и методологическая среда для людей и организаций, которым нужно понимать, проектировать, проверять и управлять ИИ, автономными системами, агентными архитектурами, AI governance, human-in-the-loop и risk-aware workflows.

## Главное правило запуска

Сначала собирается минимальная управляемая система:

```text
один вход
один курс
один demo
один сертификат
один bulletin
одна financial model
один student route
один CRM route
один тестовый запуск
```

Расширение начинается только после проверки этого маршрута на одном студенте и одной организации.
