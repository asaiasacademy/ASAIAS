# ASIAISA Academy / Академия ASIAISA

Семибуквенное имя ASIAISA имеет утверждённый двуязычный реестр допустимых прочтений R01–R11. Полная расшифровка выбирается по документу и его контексту; варианты относятся к одной Академии. Исторические документы сохраняют исходное имя и дату.

Статус: проектная образовательная и исследовательская инициатива. Репозиторий содержит публичные технические и редакционные материалы; действующие решения, паспорта программ и их статусы сверяются с нативной БЗ Bitrix24. Наличие курса или шаблона документа не подтверждает открытый набор, выдачу или аккредитацию.

## Что это

ASIAISA проектируется как образовательная и методологическая среда для людей и организаций, которым нужно понимать, проектировать, проверять и управлять ИИ, автономными системами, агентными архитектурами, AI governance, human-in-the-loop и risk-aware workflows.

## Главное правило запуска

Сначала собирается минимальная управляемая система:

```text
один вход
один курс
один demo
один сертификат
один bulletin
одна financial model
один student route
один CRM route
один тестовый запуск
```

Расширение начинается только после проверки этого маршрута на одном студенте и одной организации.
