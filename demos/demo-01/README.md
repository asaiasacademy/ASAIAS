# Demo 01: AI-Native Operating System Map

Статус: learning demo draft v1.

## Purpose

Demo показывает, как участник курса может описать AI-native operating system для команды, организации, исследовательского центра или академии.

## Safety Rule

Demo учебное. Оно не заявляет production-readiness, доход, юридическую пригодность, безопасность для критических систем или готовность к внедрению без отдельной проверки.

## Scenario

Участник выбирает одну не-критическую рабочую область, например:

- управление знаниями команды;
- подготовка исследовательского bulletin;
- учебный workflow;
- routing заявок;
- draft review process.

## Required Components

- problem statement;
- users and stakeholders;
- knowledge sources;
- workflow map;
- AI assistant role;
- human review point;
- risk notes;
- evidence output.

## Minimal Diagram

```text
input -> source map -> AI-assisted draft -> human review -> revised output -> evidence pack
```

## What Not To Claim

- production-ready;
- fully autonomous;
- guaranteed business result;
- certified compliance;
- replacement for professional judgment.
