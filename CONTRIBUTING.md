# Contributing

Статус: baseline v1.

## Как вносить изменения

1. Создать отдельную ветку от основной ветки.
2. Изменить только связанные с задачей файлы.
3. Добавить источники в `docs/source-map.md`, если изменение влияет на публичные claims.
4. Открыть pull request.
5. Дождаться review и checks.
6. Влить изменения только после approval.

## GitHub доступ

Перед любыми GitHub-операциями проверьте `docs/github-access-policy.md`.

Нельзя использовать GitHub account, SSH key, wrapper, remote или global git identity другого проекта. ASAIAS подключается только через ASAIAS-approved локальный доступ.

## Что считается вкладом

- улучшение курса;
- учебное demo;
- research source;
- перевод;
- syllabus;
- rubric;
- certificate review criteria;
- financial model note;
- intake / CRM improvement;
- site copy, если copy опирается на source map.

## Нельзя

- заявлять аккредитацию, официальный статус, партнерства или гарантии без подтверждения;
- публиковать международные claims без source map;
- хранить private student data в GitHub;
- продавать сертификат как автоматическое одобрение;
- добавлять production-claims к учебным demo;
- расширять каталог курсов до проверки первого flagship course.

## Definition of Done

Изменение готово, если:

- понятна цель;
- обновлены связанные документы;
- claims проверены;
- privacy не нарушена;
- есть понятный next action;
- reviewer может проверить результат за один проход.
